# لاگ تعاملات با هوش مصنوعی

در این فایل، تمام پرسش‌ها و پاسخ‌های مرتبط با هوش مصنوعی در طول انجام تست فنی ثبت شده است.


# تغییر کتابخانه مجازی‌سازی
- **مشکل:** react-window باگ‌های زیادی در اجرا داشت و با نسخه‌ها تداخل داشت.
- **تصمیم:** مهاجرت به @tanstack/react-virtual.
- **دلیل:** پایداری بیشتر، هم‌خوانی با اکوسیستم TanStack (مثل React Query)، و API مدرن‌تر.
- **نتیجه:** کامپوننت بدون باگ و با پرفورمنس بالا اجرا شد.
